# История изменений

## 0.5.3

- Добавлено окно «О нас» в меню TunnelGuard и под значком щита.
- Релиз доступен через команду «Проверить обновления…» в версии 0.5.2.

## 0.5.2

- TunnelGuard проверяет GitHub Releases при запуске, если с последней успешной проверки прошло больше суток. Можно проверить обновления вручную из меню приложения и значка щита.
- Если доступна новая стабильная версия с DMG для Apple Silicon и SHA-256, приложение открывает страницу этого релиза.

## 0.5.1

- Добавлены простой режим с кнопкой запуска Claude Desktop и экспертный режим с панелью.
- Значок в строке меню появляется при запуске TunnelGuard и остаётся после закрытия окна. Через него можно запустить Claude или сменить режим.

## 0.5.0

- Новая панель с боковой навигацией, интерактивным маршрутом, состоянием приложений, диагностикой и журналом.
- Защищённый запуск Claude Code в Terminal, наблюдение за службой PF, аварийная остановка, меню macOS и CLI.
- Новая проверка V2Pro и сетевого фильтра выполняется при каждом запуске Claude и при открытии уже работающего сеанса из TunnelGuard.

## 0.4.2

- Релиз для Apple Silicon поставляется в DMG со ссылкой на папку «Программы».

## 0.4.1

- Добавлен выбор акцентного цвета окна.
- Сборка релиза учитывает более медленный запуск тестового процесса на GitHub Actions.

## 0.4.0

- Обновлена главная панель со статусом Claude, временем проверки и подтверждённым IPv4.
- В настройках можно создать список IPv4, выбрать один выход или проверять весь список, а также переключить тему окна.
- Подготовка системного фильтра доступна из приложения. GitHub Actions публикует ZIP для Apple Silicon и SHA-256 по тегу версии.

## В разработке

- Собраны лабораторный Network Extension и отдельная TCP/UDP-проба.
- Добавлен бесплатный запускатор для команд с песочницей macOS и локальным прокси V2Pro. Подготовлено диагностическое окно SwiftUI.
- Добавлена проверка ожидаемого IP выхода двумя источниками. Неподтверждённый выход блокируется до передачи имени назначения приложения.
- Проверено сохранение блокировки прямых сокетов после принудительного завершения прокси. Проведён синтетический тест сетевого обмена Claude Code.
- Добавлен отдельный режим для официального Claude Desktop ARM64 в Debian VM с `nftables` и HTTPS-прокси по `vsock`.
- Добавлено окно запуска Claude Desktop с состоянием сеанса, проверкой HTTPS из гостя и подключением через «Общий экран» macOS. У приложения появилась собственная иконка.
- Версия 0.3.0 открывает установленный Claude.app напрямую. Отдельные правила PF ограничивают TCP и UDP его процессов интерфейсом V2Pro.
