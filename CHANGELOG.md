# История изменений

## 0.4.0

- Обновлена главная панель со статусом Claude, временем проверки и подтверждённым IPv4.
- В настройках можно создать список IPv4, выбрать один выход или проверять весь список, а также переключить тему окна.
- Подготовка системного фильтра доступна из приложения. GitHub Actions публикует ZIP для Apple Silicon и SHA-256 по тегу версии.

## В разработке

- Собраны лабораторный Network Extension и отдельная TCP/UDP-проба.
- Добавлен бесплатный запускатор для команд с песочницей macOS и локальным прокси V2Pro. Подготовлено диагностическое окно SwiftUI.
- Добавлена проверка ожидаемого IP выхода двумя источниками. Неподтверждённый выход блокируется до передачи имени назначения приложения.
- Проверено сохранение блокировки прямых сокетов после принудительного завершения прокси. Проведён синтетический тест сетевого обмена Claude Code.
- Добавлен отдельный режим для официального Claude Desktop ARM64 в Debian VM с `nftables` и HTTPS-прокси по `vsock`.
- Добавлено окно запуска Claude Desktop с состоянием сеанса, проверкой HTTPS из гостя и подключением через «Общий экран» macOS. У приложения появилась собственная иконка.
- Версия 0.3.0 открывает установленный Claude.app напрямую. Отдельные правила PF ограничивают TCP и UDP его процессов интерфейсом V2Pro.
