# Дальнейшая разработка

1. Довести бесплатный запуск Claude Code. Проверить интерактивную работу, обычных потомков и отдельно фоновый процесс. Зафиксировать поддерживаемую конфигурацию VPN.
2. Закрепить бесплатный гостевой режим Claude Desktop. Проверить полный сценарий входа с согласованным тестовым профилем. Нативная блокировка macOS-сборки Claude Desktop остаётся отдельной задачей.
3. Проверить реальный обрыв, восстановление, аварию фонового компонента, смену сети и IPv4/IPv6/DNS с захватом. Использовать сетевой стенд, независимый от активного V2Pro на рабочем Mac.
4. Подключить к подтверждённому механизму состояние защиты, управление приложениями и VPN-профилями, журнал и уведомления. Добавить запуск Claude из окна после проверки защиты.
5. Подготовить установку и удаление для macOS. Реализацию Windows начать после проверенной версии macOS.
